The agenda is the heart of this config: a single, calm view of what matters
today, built from all the tasks across your Org files. This page explains
how to open it, how to read it, and the visual touches that make it pleasant to
live in.

#+CAPTION: The agenda under the Solarized Light theme
[[file:../screenshots/solarized-light.png]]

* Opening it
Press =C-c p a= (Productivity → Plan & Review → Agenda), or run =M-x
ps/show-agenda=. It opens today's view immediately, taking over whichever
window you're in (splitting first only if it's the only one open) — every
other open window is left exactly as it was.

For Org's full agenda dispatcher (other built-in views, date ranges, etc.),
press =C-c a=.

* How it's organized
The agenda groups tasks into sections, in this order:

- *Schedule* — a real timeline of today's timed events, with a now-indicator
  and grid ticks (see /The schedule view/ below).
- *Scheduled today* — tasks you planned for today that have no specific time.
- *Due today* / *Overdue* — deadlines landing today or already past.
- *Scheduled earlier* — scheduled tasks you didn't get to.
- *Due soon* — upcoming deadlines.
- *High-priority* — every =[#A]= task, gathered in one place.
- *In progress* — every =INPR= task.
- *Next up* — every =NEXT= task: the shortlist of what to pick up next.

Those last three sections answer the three questions you actually have when you
sit down: /what matters/, /what am I already in the middle of/, and /what do I
start next/. Mark what's important with priority =A=, mark what you're actively
doing as =INPR=, mark the handful of things you'd start next as =NEXT= — the
agenda surfaces all three, so you rarely need a separate task list.

A task appears in *only one* of the three, so nothing is listed twice: in
progress wins over high priority, which wins over next up. An =[#A]= task you've
started shows under /In progress/ rather than /High-priority/ — its priority is
still visible on the line. (Dated tasks can appear both in the sections at the
top and in one of these three; that's intentional, since those sections answer a
different question.)

Keep /Next up/ short. It's a shortlist to scan, not a second inbox — if
everything drifts to =NEXT=, the section stops telling you anything.

The agenda is deliberately a /today/ view. To see scheduled tasks and deadlines
laid out across a week, a month, a year, or an arbitrary range — without the
high-priority, in-progress and next-up sections — use the [[file:Calendar.org][Calendar]] instead.

* Reading a line
Each task line is laid out in aligned columns so it scans cleanly:

- a *category icon* for the file the task came from (e.g. a briefcase for
  =Work.org=) — see [[file:Customization.org][Customization & appearance]] to map your own;
- the *category name*;
- compact *pills* for the TODO state and priority;
- the task text;
- a right-aligned *date/time pill* for its schedule or deadline.

=SCHEDULED= and =DEADLINE= labels are shown as small icons rather than words, to
keep lines short. Finished (=DONE=) tasks are faded so they recede.

Markup you wrote in a task's heading — =*bold*=, =/italic/=, =code=, =~verbatim~=
and the rest — is rendered in the agenda the same way it is in the file: the
text is styled and the markers themselves are not shown.

* The schedule view
The *Schedule* section renders the day as a time axis with a left-hand time
column (=HH:MM-HH:MM ┆=). Two styles are available from *Productivity →
Schedule View*:

- *Timeline* — shows the full time axis, with a tick row for each grid interval
  between events. Best when you want to see the complete shape of the day.
- *Events* — shows only the timed events, hiding the empty grid rows for a
  compact list.

Overlapping events are flagged with =⚠ overlap= at the right edge (the
[[file:Planning-tools.org][conflict checker]] does a more thorough pass).

*Auto-refresh* (on by default, toggle in the same menu) regenerates the agenda
at the start of each minute so the now-indicator and DONE visibility stay
current; your cursor and scroll position are preserved.

* Moving around in the agenda
The agenda is read-only-ish — you act on tasks without leaving it:

| Key           | Action                             |
|---------------+------------------------------------|
| =n= / =p=     | next / previous line               |
| =RET=         | jump to the task in its file       |
| =SPC= / =TAB= | peek at the task in another window |
| =t=           | change the task's TODO state       |
| =,=           | set its priority                   |
| =:=           | set its tags                       |
| =r= / =g=     | refresh the agenda                 |
| =q=           | quit the agenda window             |

* Folding sections
Agenda sections can be collapsed. Press =TAB= (or click a section header) to
fold/unfold it; =M-x ps/agenda-fold-collapse-all= and =ps/agenda-fold-expand-all=
toggle everything at once. You can choose which sections start collapsed — see
below.

* The mode line
The mode line (the status strip at the bottom of each window) is tuned for this
planning environment rather than left at the Emacs default: it shows the file
name, your position, and the current heading path, separated by a thin =·=. The
heading path is shown as plain text — links collapse to their name (an
=obsidian:= link shows just its note title) and emphasis markers like =*bold*=
are dropped. Like
=org-super-agenda= grouping and the layout pills, it's part of making the
planning view readable — not a cosmetic theme choice. Its colors follow whatever
[[file:Customization.org][theme]] you pick.

In any of the five planning-view buffers — Agenda, [[file:Calendar.org][Calendar]],
[[file:Tasks-view.org][Tasks]], [[file:Planning-tools.org][Availability]], or
[[file:Planning-tools.org][Conflicts]] — the leading title (e.g. =Agenda ▾=) is
also a *view switcher*: click it to pop up a menu and jump straight to any
other view, [[file:Situations.org][situations]] included — it mirrors
Productivity → Plan & Review exactly, and it is the same
click-a-label-for-a-menu interaction as the
[[file:Files-and-navigation.org][file tree]]'s file-set selector. Whichever
view you switch to takes over the window you're in, leaving any other open
window untouched (splitting first only if that window is the only one open).

When the Agenda finds scheduling conflicts, a count (e.g. =⚠ 2 conflicts=)
appears next to the title — in the mode line's normal text, not a warning
color, so it informs without shouting. Click it to open the full
[[file:Planning-tools.org][conflict checker]]. It only appears for the Agenda
view; switching to Calendar or Tasks clears it.

* Under the hood / Customize
- The sections come from =org-super-agenda= and the custom command =c=, defined
  in =config.org= → /Org Mode → Agenda → Super agenda/. Edit the shared list
  =ps/agenda-day-super-groups= there to add, remove, or reorder sections; it also
  feeds the [[file:Calendar.org][Calendar]]'s day view and the default styling of Org's stock agenda
  (=C-c a= then =a=) and of clicking a date stamp in an Org file.
- The aligned layout, pills, category/schedule icons, emoji, and folding are the
  modules =lisp/ps-agenda-layout.el=, =ps-agenda-icons.el=,
  =ps-schedule-icons.el=, =ps-agenda-emoji.el=, and =ps-agenda-fold.el=; their
  settings live in the matching =config.org= blocks.
- Org markup in task text is rendered by =lisp/ps-emphasis.el= (no settings).
- The schedule view is =lisp/ps-schedule-view.el=; defaults
  (=ps/schedule-view-style=, =ps/schedule-view-auto-refresh=) are in =config.org=
  → /Schedule view/.
- Which sections start folded: =ps/agenda-fold-default-collapsed= in =config.org=
  → /Agenda fold/.
- The mode line is =lisp/ps-mode-line.el=; its separator is
  =ps/mode-line-separator= in =config.org= → /Mode line/. The view-switcher
  popup is =ps/mode-line--agenda-click=, in the same file.
