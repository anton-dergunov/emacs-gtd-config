Welcome. This is a minimalist Emacs configuration for planning your work and
life in plain-text [[https://orgmode.org/][Org Mode]] files, with a clean visual
*agenda* at its centre. The workflow is inspired by /Getting Things Done/: keep
your tasks and notes in a few Org files, and let the agenda show what matters
today.

This documentation is written in Org so it reads well both on GitHub and
*inside Emacs itself* — open any =.org= file here and images, links, and
folding just work.

New to Emacs? Follow the pages roughly top to bottom. Already comfortable with
Emacs? Jump to [[file:planning-setup.org][Planning your work]].
