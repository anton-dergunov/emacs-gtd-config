#+TITLE: Notes & links
#+OPTIONS: toc:t
#+STARTUP: inlineimages

Linking ties your tasks and notes to the things they're about — web pages, and
notes in an [[https://obsidian.md/][Obsidian]] vault. This config adds a few conveniences on top of Org's
own linking.

* Web links with the title filled in
Instead of pasting a bare URL, this inserts a proper Org link whose description
is the page's *real title*, fetched for you in the background (Emacs stays
responsive while it loads).

- Press *=F6=* or *=C-c p u=* (Productivity → Insert Links → URL with
  Auto-title), or =M-x ps/org-insert-link-async=.
- Paste or type the URL; the finished =[[url][Page Title]]= link drops in once
  the title arrives.

The fetched title is trimmed to a sensible length so links stay readable.

* Obsidian links
If you keep notes in Obsidian, these insert =obsidian:= links that open the note
in Obsidian, and display nicely inside Emacs:

- *=F4=* / *=C-c p o=* — insert an Obsidian link from the *clipboard* (copy an
  Obsidian link in the app first).
- *=F5=* / *=C-c p O=* — insert an Obsidian link by *typing/prompting* for the
  note.

* Plain Org links
For everything else, Org's own linking still applies:

- =C-c p l= (=org-store-link=) — remember a link to the current location.
- =C-c C-l= — insert a link (and paste a stored one).
- =C-c C-o= — open the link at point.

* Under the hood / Customize
- The async URL→title command and the Obsidian link type live in
  =lisp/ps-links.el= (with title helpers in =lisp/ps-utils.el=).
- The maximum fetched-title length is =ps/org-link-title-max-length= in
  =config.org= → /Links/.
