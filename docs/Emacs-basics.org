New to Emacs? This page is the minimum you need to feel at home before using
the rest of this documentation. You don't have to memorize it — keep it open in
a window and refer back.

* Reading the notation
Emacs key notation is compact:

- =C-x= means hold *Control* and press =x=.
- =M-x= means hold *Meta* (=Alt= on most keyboards, =Option= on macOS) and
  press =x=. If Meta is awkward, you can always press =Esc= then the key
  instead.
- =S-= means *Shift*; =RET= is Return/Enter; =SPC= is Space; =TAB= is Tab.
- =C-c p a= means press =C-c=, then =p=, then =a= in sequence.

* The two keys that save you
- =C-g= — *cancel.* Pressed anything by accident, or stuck in a half-typed
  command? =C-g= quits it and returns you to a normal state. When in doubt, press
  =C-g=.
- =C-/= — *undo* (also =C-x u=). Redo by undoing after a =C-g=, or use =C-?=.

* Moving the cursor
| Key           | Moves to                         |
|---------------+----------------------------------|
| =C-f= / =C-b= | forward / backward one character |
| =M-f= / =M-b= | forward / backward one *word*    |
| =C-a= / =C-e= | start / end of the line          |
| =C-n= / =C-p= | next / previous line             |
| =M-<= / =M->= | beginning / end of the buffer    |
| =C-v= / =M-v= | down / up one screen             |

The arrow keys, Home/End, and Page Up/Down all work too — the bindings above
just keep your hands on the home row.

* Editing text
- *Delete:* =C-d= deletes the character ahead; Backspace deletes behind.
- *Kill (cut):* =C-k= kills to end of line; =M-d= kills the next word. Killed
  text goes to the "kill ring".
- *Yank (paste):* =C-y= yanks the last kill; =M-y= cycles through earlier kills.
- *Select a region:* set a mark with =C-SPC=, move the cursor, then act on the
  highlighted region (=C-w= to cut, =M-w= to copy). A selection stays put when
  you move to another window, shown in a paler colour — see
  [[file:Customization.org][Customization & appearance]].
- The usual =Cmd/Ctrl-C= / =Cmd/Ctrl-V= often work too, depending on your build.

* Files
| Key       | Action                  |
|-----------+-------------------------|
| =C-x C-f= | open (find) a file      |
| =C-x C-s= | save the current file   |
| =C-x s=   | save all modified files |
| =C-x C-c= | quit Emacs              |

In this config, Org files auto-save and auto-revert, so you rarely press
=C-x C-s= yourself — see [[file:Sync-and-backups.org][Sync & backups]].

* Buffers and windows
A *buffer* is an open document; a *window* is a pane showing one. Splitting lets
you see several at once.

| Key     | Action                                        |
|---------+-----------------------------------------------|
| =C-x 1= | keep only the current window (close the rest) |
| =C-x 2= | split *horizontally* (one above the other)    |
| =C-x 3= | split *vertically* (side by side)             |
| =C-x 0= | close the current window                      |
| =C-x o= | move focus to the other window                |
| =C-x b= | switch buffer                                 |
| =C-x k= | close the current buffer                      |

To close *everything* at once — useful after reorganizing your Org folder, when
buffers are still pointing at the old paths — run =M-x desktop-clear=. It closes
every buffer and empties the saved session, so the next restart doesn't bring
the old ones back.

This config adds =C-x |= (also =C-c p |=) to flip an existing split between
horizontal and vertical — handy when the agenda and a file end up stacked the
wrong way. See [[file:Files-and-navigation.org][Files & navigation]].

* Running commands
Every command has a name. Press =M-x=, start typing, and pick from the list —
this is how you reach anything without a key. The commands this config adds are
named =ps/...=, so =M-x ps/= shows them all.

* Completion and search
This config uses a friendly completion stack, so typing in any prompt filters a
live list of matches:

- *Ivy/Counsel* — narrow files, buffers, and command results as you type.
- *Swiper* (=C-s=) — search the current buffer with a live preview of matches.

* Getting help
The help system is excellent and always one key away:

- =C-h k= then a key → "what does this key do?"
- =C-h f= → describe a function (=ps/...= commands are documented here).
- =C-h v= → describe a variable (every =ps/...= setting is here too).
- =C-h m= → describe the current mode and its keys.

*which-key:* whenever you press a prefix like =C-c p= or =C-x= and pause, a
popup lists every key that can follow. You can explore the whole config this
way without reading any code.
