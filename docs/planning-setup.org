#+OPTIONS: toc:t

This page explains how your Org files are organized, the task states and
priorities this config uses, and the everyday Org-mode keys for editing tasks.

The workflow is *inspired by* [[https://en.wikipedia.org/wiki/Getting_Things_Done][Getting Things Done]] — capture things out of your
head, keep them in plain-text files, and review a single agenda that surfaces
what's relevant now. It isn't a strict implementation of the methodology; treat
it as a calm, lightweight starting point you can shape to your own taste.

* Your Org files
Everything lives under the one base directory you set in =local.el=
(=my-org-base-directory= — see [[file:installation.org][Installation]]). The recommended layout:

#+begin_example
<my-org-base-directory>/
├── Areas/      one .org file per area of life/work — scanned for the agenda
│                 (e.g. Career.org, Health.org, Projects.org, Inbox.org, …)
├── Vision/     long-term vision and yearly goals (not scanned)
├── Current/    your current focus / weekly review (not scanned)
└── workspace.org   per-folder settings (icons, file sets) — optional
#+end_example

- *=Areas/=* is the important one: every =.org= file in it (recursively) feeds
  the agenda. Make one file per area of responsibility — a project, a part of
  your job, a hobby. =Inbox.org= is a good place to dump new items.
- *=Vision/=* and *=Current/=* are yours to use freely; the agenda doesn't scan
  them automatically.
- *=workspace.org=* holds settings tied to /this/ data folder (your category
  icons, your file-tree sets) — see [[file:customization.org][Customization & appearance]].

A working example of this whole layout ships in =samples/realistic/=.

* Task states
A task is a headline that starts with a keyword. This config uses a short
sequence (kept to four characters so the agenda stays compact):

| Keyword | Meaning                                              |
|---------+------------------------------------------------------|
| =TODO=    | something to do, not started                         |
| =NEXT=    | a concrete next action                               |
| =INPR=    | in progress right now                                |
| =WAIT=    | blocked / waiting on someone or something            |
| =MAYB=    | maybe / someday — not committed                      |
| =DONE=    | finished (drops out of the active agenda)            |

In practice many people lean on *=INPR=* plus *priorities* (below) rather than
=NEXT= to decide what to work on — the agenda has dedicated /In progress/ and
/High-priority/ sections for exactly this.

* Priorities
Tasks can carry a priority cookie =[#A]=, =[#B]=, or =[#C]= (A is highest). The
agenda gathers all =[#A]= tasks into a *High-priority* section, so marking the
few things that truly matter today is enough to make them stand out.

* A first task
Open any file under =Areas/= and write:

#+begin_example
* My Project
** TODO [#A] Write the proposal
** INPR Draft the outline
** TODO Call the bank
   DEADLINE: <2026-07-01 Wed>
** TODO Team sync
   SCHEDULED: <2026-06-22 Mon 13:30-15:00>
#+end_example

- =DEADLINE:= — when something is *due*. It shows up in /Due today/, /Due soon/,
  or /Overdue/.
- =SCHEDULED:= — when you plan to *work on* it. A scheduled time-of-day appears
  on the timeline in the agenda.

The easiest way to add these dates is the keys below — you don't type the
=<...>= brackets by hand.

* Editing tasks: the essential keys
These are standard Org-mode bindings, used while editing an Org file (not the
agenda). They're worth committing to muscle memory.

| Key            | Action                                                    |
|----------------+-----------------------------------------------------------|
| =C-c C-t=        | change the TODO state (pick from the list)                |
| =S-→= / =S-←=     | cycle the TODO state right / left without a menu          |
| =C-c ,=          | set the priority (=A=/=B=/=C=, or =SPC= to clear)          |
| =C-c C-s=        | add/edit a *SCHEDULED* date (calendar picker)             |
| =C-c C-d=        | add/edit a *DEADLINE* date                                |
| =M-RET=          | new headline/task at the same level, below the current   |
| =M-→= / =M-←=     | demote / promote the heading (change its level)           |
| =M-↑= / =M-↓=     | move the whole subtree up / down among its siblings       |
| =C-c C-c=        | set tags on a heading (also: act on the thing at point)   |

* Folding: see more or less
Org files are outlines you can collapse and expand:

- =TAB= — fold/unfold the subtree under the current heading.
- =S-TAB= — cycle the *whole buffer* between overview, contents, and full
  detail. Press it a few times to get a feel for it.
- =C-u C-u TAB= — reset the buffer to its startup folding.

This config also fades and folds *DONE* tasks so finished work recedes visually
— see [[file:files-and-navigation.org][Files & navigation]] and [[file:agenda.org][The Agenda]].

* Under the hood / Customize
- The task keywords are defined once in =config.org= → /Org Mode → Agenda →
  TODO keywords/ (=org-todo-keywords=). Change them there; nothing in the code
  hardcodes the names. Keep each keyword ≤ 4 characters so the agenda pills stay
  compact.
- The =Areas/= scan is =ps/agenda-files-refresh= in =config.org= → /Agenda files/.
