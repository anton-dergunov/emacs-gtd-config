#+TITLE: Emacs Configuration for Productivity, Planning, "Getting Things Done" and Knowledge Management with Org Mode

This config is tangled and loaded by =init.el=. Self-contained logic lives in
=lisp/ps-*.el= modules and is ERT-tested; this file is configuration only.

If you are reading this to make it your own, the only section you usually need is
=* Settings= below — color theme, font, and every module knob live there.

* Bootstrap
** Package management
The first block carries the =-*- lexical-binding: t; -*-= cookie that the tangled
file needs. Do not move it.
#+begin_src emacs-lisp
  ;; -*- lexical-binding: t; -*-
  ;; Code above enables lexical scoping so lambdas can capture variables (needed for async code)

  ;; Disable the org-element cache for runtime Org use.  Without this,
  ;; Org can hit "Invalid search bound (wrong side of point)" while
  ;; parsing this very file — before the Org Mode section sets it later.
  ;; NOTE: the authoritative *tangle-time* guard lives in init.el, set
  ;; before `org-babel-load-file' tangles this file; this line cannot
  ;; protect that tangle since it only takes effect once config.el is
  ;; already built and loaded. Kept here as belt-and-suspenders.
  (setq org-element-use-cache nil)

  ;; Don't pop up the *Warnings* buffer when third-party packages byte/native-
  ;; compile on first install (e.g. guess-language emits a few harmless warnings
  ;; in its own source). Warnings are still logged to *Async-native-compile-log*,
  ;; and our own ps-* modules are kept warning-clean regardless.
  (setq native-comp-async-report-warnings-errors 'silent)

  (require 'package)

  ;; Initialize package sources if needed
  (setq package-archives '(("melpa" . "https://melpa.org/packages/")
                           ("elpa" . "https://elpa.gnu.org/packages/")))

  ;; Refresh package contents if needed
  (unless package-archive-contents
    (package-refresh-contents))

  ;; Install use-package if missing
  (unless (package-installed-p 'use-package)
    (package-install 'use-package))

  (require 'use-package)
  (setq use-package-always-ensure t)
#+end_src

** Auto-tangle this config on save
Saving =config.org= in a live session regenerates =config.el= immediately.
Because this tangle runs in a fully-initialized Emacs (org-element cache already
off, Org fully loaded) it is always clean — unlike the tangle =init.el= performs
at startup. It also leaves =config.el= newer than =config.org=, so the next
restart skips startup tangling entirely and just loads a known-good file.
#+begin_src emacs-lisp
  (defun ps/tangle-config-on-save ()
    "Tangle config.org -> config.el after saving config.org.
  Runs in the live session (org-element cache already off, Org fully
  loaded), so the tangle is clean — unlike the tangle init.el performs at
  startup. Regenerating config.el here also makes it newer than config.org,
  so the next restart skips startup tangling and just loads it."
    (let ((config (expand-file-name "config.org" user-emacs-directory)))
      (when (and buffer-file-name
                 (string= (file-truename buffer-file-name)
                          (file-truename config)))
        (let ((org-confirm-babel-evaluate nil))
          (org-babel-tangle-file
           config
           (expand-file-name "config.el" user-emacs-directory)
           "emacs-lisp")))))

  (add-hook 'after-save-hook #'ps/tangle-config-on-save)
#+end_src

** Material icons (ps-material-icons.el)
Category icons (in the agenda and the file tree) are drawn from the "Material
Symbols Outlined" font — no per-icon SVG files. See the README for installing

The =category-map= (=<Category>.org= → icon name) and =folder-map= (whole-folder
icons) are left *empty* here: =config.org= renders every file with the generic

=workspace.org= (see "Workspace config" below), so your personal categories
never enter this public repo. Names come from https://fonts.google.com/icons.

#+end_src

** File Tree (ps-file-tree.el / ps-file-tree-icons.el)
Files/dirs whose name matches any regexp here are hidden from the file tree
(=init.org=, dotfiles, =elpa/=, byte-compiled files by default). Category icons
come from the Material Symbols font (see above); =ps/file-tree-icon-ascent= sets

If the font is unavailable, the tree falls back to the =folder=/=folder_open=
/=draft= SVGs in =ps/file-tree-icon-fallback-dir=. Set =ps/file-tree-use-custom-icons=
to =nil= to use treemacs's generic icons instead.

  (setq ps/file-tree-use-custom-icons t)
  (setq ps/file-tree-name-spacing 0.5)
  (setq ps/file-tree-icon-ascent 80)
  (setq ps/file-tree-icon-fallback-dir
        (expand-file-name "icons" user-emacs-directory))
#+end_src

*** File sets
Named filters for which files the tree shows — by default this is purely
a display filter, and the agenda and everything else still see every
file. Each set has =:include= and/or =:exclude= regexps, matched as
substrings of each file's absolute path. "All" (the default) shows
everything, and is also the fallback used if =ps/file-tree-current-set=
ever names a set that no longer exists. The active set is shown and
switched from the file tree's mode line, and persists across restarts.
#+begin_src emacs-lisp
  (setq ps/file-tree-file-sets
        '(("All" . (:include nil :exclude nil))
          ;; ;; Examples:
          ;; ("Work" . (:include ("/Areas/Work\\.org\\'"
          ;;                      "/Current/")
          ;;            :exclude nil))
          ;; ("No Sensitive" . (:include nil
          ;;                     :exclude ("/Areas/Financial\\.org\\'"
          ;;                               "/Areas/Interviews\\.org\\'")))
          ))
#+end_src

** Agenda emoji matcher (ps-agenda-emoji.el)
The agenda appends a semantic emoji to each task. Matches come from

** Agenda layout (ps-agenda-layout.el)
The agenda task lines are re-laid into aligned columns:
=[category] [STATE] [PRIORITY] [emoji]  Title… [tags]   [when]=. State, priority
and the relative date ("11d ago") are drawn as rounded pill badges; titles line
up across every section and are truncated (full text shown on hover) when they
would overflow.

- =category-display=: =icon= (default), =name=, =both=, or =none=.
- =schedule-style=: =grid= keeps Org's native time ruler; =compact= hides the
  empty grid rows and lays timed events out like the other sections. Switch and
  press =g= in the agenda to compare.
- =state-labels=: remap a keyword to a shorter label, e.g. ="WAIT" → "W"= (the
  actual TODO keyword is unchanged). Rarely needed now that all keywords are ≤4
  chars. Empty = show keywords verbatim.
- =state-cols= is auto-computed from the longest keyword + 2 padding spaces when
  left at =nil=; set to an integer to override. =priority-cols= is =4= (covers
  =" #A "=). State and priority badges use =org-modern= faces, so their colours
  follow the active theme automatically — no per-theme colour overrides needed.
#+begin_src emacs-lisp
  (setq ps/agenda-layout-enabled        t
        ps/agenda-layout-category-display 'icon   ; icon | name | both | none
        ps/agenda-layout-schedule-style   'grid   ; grid | compact
        ps/agenda-layout-state-labels     nil     ; e.g. '(("WAIT" . "W"))
        ps/agenda-layout-truncate         t
        ps/agenda-layout-priority-cols    3
        ps/agenda-layout-emoji-cols       2
        ps/agenda-layout-category-cols    2
        ps/agenda-layout-right-margin-cols 1)
#+end_src

** Schedule view (ps-schedule-view.el)
Replaces the native time-grid rendering for the Schedule section with two
styles, switchable from the =Productivity → Schedule View= menu:

- =Timeline= — shows the full time axis: a tick row for each grid interval
  appears between timed events.  Useful when you want to see the complete time
  structure of the day.
- =Events= — shows only the timed events; grid-tick rows are hidden for a more
  compact view.

Both styles use a left-hand time column (=HH:MM-HH:MM ┆=) with task body
columns identical to the other sections (just shifted right by the time prefix).
Overlapping events are flagged with =⚠ overlap= at the right edge.

=auto-refresh=: when enabled (default), the agenda is re-generated at the
start of each calendar minute so the now-indicator and DONE-task visibility stay
current.  Cursor and scroll position are preserved across refreshes.
#+begin_src emacs-lisp
  (setq ps/schedule-view-style       'timeline   ; timeline | events
        ps/schedule-view-auto-refresh t)
  (ps/schedule-view-setup)
#+end_src

** Typo / spell checking (ps-typo.el)
A quiet, multilingual typo checker for Org buffers. A word is underlined only
when *no* configured language recognises it, so terms valid in any of your
languages (e.g. Spanish =calor=, Cyrillic words) are never flagged. Code, links
and markup are skipped automatically. Correct a word with =M-$=.

=ps/typo-languages= is the union of accepted languages — extend it for every
language you write in (each needs an =enchant= dictionary; see README.md).
=ps/typo-near-miss-gate= is an extra-precision mode (only flag words that look
like a near miss of a real word); it is off by default so you can experiment.
=ps/typo-order-suggestions-by-language= lists fixes for the locally-detected
language first; set it to nil to disable. =ps/typo-underline-color= is the wavy
underline colour (=auto= derives a muted colour from the theme's =shadow= face).
#+begin_src emacs-lisp
  (setq ps/typo-languages       '("en_US" "ru_RU" "es_ES")
        ps/typo-min-length      3
        ps/typo-near-miss-gate  nil   ; t = only flag near-misses of real words
        ps/typo-near-miss-max-distance 2
        ps/typo-order-suggestions-by-language t
        ;; Solarized keeps a soft grey; other themes derive one from `shadow'.
        ps/typo-underline-color (if ps/color-theme-solarized-p "gray60" 'auto))
#+end_src

** Workspace config (per-Org-folder overrides)
A small =workspace.org= in your Org base directory (beside =init.org=) holds
settings specific to *this data folder* — personal category→icon mappings and
file sets — overriding the (intentionally empty) defaults above. It is loaded
here, after those defaults but before icons are applied, so its overrides take
effect. Keeping personal data there (not in =config.org=) means pulling upstream
changes never conflicts. It is loaded artifact-free: its elisp is tangled to a
throwaway file in the system temp dir, never inside your Org folder.
#+begin_src emacs-lisp
  (defun ps/workspace-config-file ()
    "Return the path to this Org folder's workspace.org."
    (expand-file-name "workspace.org" my-org-base-directory))

  (defun ps/load-workspace-config ()
    "Load emacs-lisp from workspace.org, if it exists.
Tangles its blocks to a temp .el in the system temp dir (never the Org dir),
loads it, then deletes it. Silently does nothing when the file is absent."
    (let ((file (ps/workspace-config-file)))
      (when (file-exists-p file)
        (require 'ob-tangle)
        (let ((el (make-temp-file "ps-workspace-" nil ".el")))
          (unwind-protect
              (let ((org-confirm-babel-evaluate nil))
                (org-babel-tangle-file file el "emacs-lisp")
                (load el nil t))
            (when (file-exists-p el) (delete-file el)))))))

  (defun ps/icons-reapply ()
    "Re-apply agenda and file-tree icons from the current maps."
    (ps/agenda-icons-apply)
    (when (and ps/file-tree-use-custom-icons (featurep 'treemacs))
      (ps/file-tree-icons-apply my-org-base-directory)
      (when (fboundp 'ps/file-tree--refresh) (ps/file-tree--refresh))))

  (defun ps/open-workspace-config ()
    "Open this Org folder's workspace.org (a fresh buffer if it doesn't exist)."
    (interactive)
    (find-file (ps/workspace-config-file)))

  (defun ps/reload-workspace-config ()
    "Reload workspace.org and re-apply icons and file sets."
    (interactive)
    (ps/load-workspace-config)
    (ps/icons-reapply)
    (when (fboundp 'ps/agenda-files-refresh) (ps/agenda-files-refresh))
    (message "Workspace config reloaded"))

  ;; Apply this folder's overrides now, before icons are built below.
  (ps/load-workspace-config)
#+end_src

  ;; Major modes that must NEVER show line numbers. Stock Emacs has no built-in
  ;; exempt list for `global-display-line-numbers-mode' — its turn-on function
  ;; only skips the minibuffer and otherwise enables numbers in every buffer.
  ;; Disabling the minor mode from a mode hook is fragile: the global mode
  ;; re-evaluates buffers on major-mode changes and can re-enable numbers when a
  ;; buffer is rebuilt, which is how the File Tree (treemacs) intermittently
  ;; ended up with line numbers (its buffer is recreated on toggle / visibility-
  ;; set switches). Instead, refuse to turn numbers on for these modes at the
  ;; source, so the decision holds every time the global mode evaluates a buffer.
  (defvar ps/display-line-numbers-exempt-modes
    '(treemacs-mode term-mode shell-mode eshell-mode org-agenda-mode)
    "Major modes for which global line numbers must never be enabled.")

  (advice-add 'display-line-numbers--turn-on :before-while
              (lambda (&rest _)
                (not (apply #'derived-mode-p ps/display-line-numbers-exempt-modes)))
              '((name . ps/display-line-numbers-exempt)))
#+end_src

** Color theme
Loads =ps/color-theme= from Settings, auto-installing the package that provides it
when needed. The Solarized-specific tuning below only runs for =solarized-*=
themes; any other theme loads cleanly without it.
#+begin_src emacs-lisp
  ;; Theme-name prefix -> package that provides it. Built-in themes (e.g. modus-*
  ;; on Emacs 28+) install only if not already available, so listing them is harmless.
  (defvar ps/color-theme-packages
    '(("modus-"      . modus-themes)     ; accessible "default" style (built-in 28+)
      ("ef-"         . ef-themes)        ; colorful + legible (GNU ELPA)
      ("standard-"   . standard-themes)  ; faithful-to-default-Emacs, refined (GNU ELPA)
      ("doric-"      . doric-themes)     ; minimalist (GNU ELPA)
      ("doom-"       . doom-themes)      ; the popular megapack (MELPA)
      ("batppuccin-" . batppuccin)       ; Catppuccin, as 4 proper themes (MELPA)
      ("tokyo-night" . tokyo-night)      ; Tokyo Night, 4 variants (MELPA)
      ("gruvbox"     . gruvbox-theme)    ; retro groove (NonGNU ELPA / MELPA)
      ("nord"        . nord-theme)       ; arctic palette (MELPA)
      ("solarized-"  . solarized-theme)) ; default theme, kept for back-compat
    "Alist of (THEME-NAME-PREFIX . PACKAGE) for auto-installing theme packages.")

  (defun ps/load-color-theme (theme)
    "Install (if needed) and load THEME, applying Solarized tuning when relevant."
    (let* ((name (symbol-name theme))
           (pkg (cdr (seq-find (lambda (c) (string-prefix-p (car c) name))
                               ps/color-theme-packages))))
      ;; Pull in the providing package unless THEME is already available.
      (when (and pkg (not (memq theme (custom-available-themes))))
        (unless (package-installed-p pkg)
          ;; Always refresh: the cached archive contents may predate this
          ;; package's addition to MELPA/GNU ELPA, or reference a since-pruned
          ;; tarball version, both of which surface as "package unavailable".
          (package-refresh-contents)
          (package-install pkg))
        (require pkg nil t))
      ;; Solarized-only tuning (these variables don't exist for other themes).
      (when (string-prefix-p "solarized-" name)
        (setq
         solarized-distinct-fringe-background nil  ; fringe blends with background
         solarized-use-variable-pitch nil          ; keep one font for headings/titles

*** Uniform blank lines between agenda sections
=org-agenda-block-separator= "" emits two newlines before each separate agenda
block (=High-priority=, =In progress=), while org-super-agenda groups are
single-spaced — so those two sections get an extra blank line. Collapse any run
of more than one blank line so every section has exactly one blank line above
it.
#+begin_src emacs-lisp
  (defun ps/agenda--single-blank-lines ()
    "Collapse runs of >1 blank line in the agenda to a single blank line."
    (let ((inhibit-read-only t))
      (save-excursion
        (goto-char (point-min))
        (while (re-search-forward "\n\n\n+" nil t)
          (replace-match "\n\n")))))
  (add-hook 'org-agenda-finalize-hook #'ps/agenda--single-blank-lines)

#+begin_src emacs-lisp
  ;; Auto-save all Org buffers
  ;; https://christiantietze.de/posts/2019/03/sync-emacs-org-files/
  ;; Save quietly: `org-save-all-org-buffers' echoes "Saving all Org
  ;; buffers... done" on every auto-save, which both flashes in the echo
  ;; area and piles up in *Messages* when Emacs runs for days.  Binding

  ;; while Emacs is idle can re-enter AppKit's event loop and hard-freeze the
  ;; whole UI (no keyboard/mouse input). Notification-based reverts avoid that
  ;; recurring timer, and silencing revert output avoids extra echo-area
  ;; redisplay.
  (setq auto-revert-avoid-polling t
        auto-revert-verbose nil
        auto-revert-check-vc-info nil)

** =treemacs= file tree
A tree-style sidebar for browsing the Org GTD tree.
The ignore list and category icons live in =lisp/ps-file-tree.el= and
=lisp/ps-file-tree-icons.el=.
#+begin_src emacs-lisp
  (use-package treemacs
    :defer t
    :commands (treemacs treemacs-select-window)
    :config
    (ps/file-tree-setup-ignore)
    (ps/file-tree--ensure-valid-set)
    (if ps/file-tree-use-custom-icons
        (ps/file-tree-icons-apply my-org-base-directory)
      (treemacs-load-theme "Default"))

    ;; Replace the file tree's mode line entirely with the active file-set
    ;; indicator; click it to switch sets.
    (setq treemacs-user-mode-line-format '(:eval (ps/file-tree--modeline)))

    ;; Root project labels (Areas/Current/Vision) should look like ordinary
    ;; file-tree entries (not underlined or oversized like the default
    ;; hyperlink-style root face), but bold to stand out as section headers.
    (set-face-attribute 'treemacs-root-face nil
      :inherit 'treemacs-file-face
      :height 1.0
      :weight 'bold
      :underline nil)

    ;; Narrower than treemacs's 35-column default.
    (setq treemacs-width 25)

    ;; Allow the tree window to be resized like any other window.
    (setq treemacs-width-is-initially-locked nil)

    ;; More compressed indentation per level (default is 2).
    (setq treemacs-indentation 1)

    ;; Hide the .org extension and add breathing room after icons.
    (setq treemacs-file-name-transformer #'ps/file-tree-transform-file-name)
    (setq treemacs-directory-name-transformer #'ps/file-tree-transform-dir-name)

    ;; Never follow the current buffer/file - the tree stays where it is.
    (treemacs-follow-mode -1)
    (treemacs-tag-follow-mode -1)

    ;; This is a curated org-category navigator, not a code-project view, so
    ;; don't tint files by git status (a modified file would otherwise show in
    ;; treemacs-git-modified-face, e.g. blue, hiding the category styling).
    (when (fboundp 'treemacs-git-mode) (treemacs-git-mode -1))

    (add-hook 'treemacs-mode-hook (lambda () (display-line-numbers-mode 0)))
    (add-hook 'treemacs-mode-hook
      (lambda () (setq-local frame-title-format "File Tree")))

    ;; Restore some vertical breathing room between entries.
    (add-hook 'treemacs-mode-hook (lambda () (setq-local line-spacing 2)))

    ;; treemacs toggles a node on button *press* (down-mouse-1) when its icon
    ;; is clicked; our release handler toggles again, causing an icon click to
    ;; expand-then-collapse. Suppress the press action so the release handler
    ;; does a single, consistent toggle.
    (define-key treemacs-mode-map [down-mouse-1] #'ignore)

    ;; Click a label to open it on the right (file, or org heading position
    ;; for tag nodes). Click an icon, or shift-click a label, to
    ;; expand/collapse — a no-op on leaf nodes. TAB still shows an org file's
    ;; structure.
    (define-key treemacs-mode-map [mouse-1] #'ps/file-tree-click)
    (define-key treemacs-mode-map [S-mouse-1] #'ps/file-tree-shift-click)

    ;; The right-click "Open" action (`treemacs-visit-node-no-split') errors
    ;; with "stringp, nil" on an org heading that has sub-headings. Route org
    ;; heading (tag) nodes through our own open logic, which jumps to the
    ;; heading position; everything else behaves as before.
    (define-advice treemacs-visit-node-no-split
        (:around (orig-fn &rest args) ps/file-tree-open-org-heading)
      (let ((btn (treemacs-current-button)))
        (if (and btn (memq (treemacs-button-get btn :state)
                           '(tag-node-open tag-node-closed tag-node)))
            (ps/file-tree--click-label)
          (apply orig-fn args))))

    ;; Non-intrusive expand/collapse-all, local to the tree buffer.
    (define-key treemacs-mode-map (kbd "M-+") #'ps/file-tree-expand-all)
    (define-key treemacs-mode-map (kbd "M--") #'ps/file-tree-collapse-all)

    ;; Keep the file tree visible across agenda window reorganization
    ;; (org-agenda's default window setup would otherwise close it).
    (with-eval-after-load 'org-agenda
      (define-advice org-agenda (:around (orig-fn &rest args) ps/file-tree-preserve)
        "Keep the file tree visible across agenda window reorganization."
        (let ((open (ps/file-tree-window-exists-p)))
          (when open (ps/file-tree-hide))
          (apply orig-fn args)
          (when open (ps/file-tree-show))))))

  ;; Open the file tree at `my-org-base-directory' on startup, one project per
  ;; immediate subdirectory, fully expanded. treemacs expands directories
  ;; asynchronously (git-status/flatten-dirs subprocesses), so re-run the
  ;; idempotent setup a few times to ride out late-arriving updates.
  (add-hook 'emacs-startup-hook
    (lambda ()
      (require 'treemacs)
      (save-selected-window
        (treemacs-select-window)
        (let ((base (treemacs-canonical-path my-org-base-directory)))
          (dolist (delay '(0 0.3 0.8 1.5 3))
            (run-with-timer delay nil #'ps/file-tree-init base))))))
#+end_src

** Toggle horizontal/vertical split (=C-x |=)
#+begin_src emacs-lisp
  ;; Partially reuses the code from:
  ;; https://emacs.stackexchange.com/questions/5371/how-to-change-emacs-windows-from-vertical-split-to-horizontal-split
  (defun ps/window-split-toggle ()
    "Switch the two windows between a horizontal (top/bottom) and vertical
\(left/right) split, keeping their order: left<->top and right<->bottom."
    (interactive)
    ;; Check if the file tree is open
    (let ((tree-open (ps/file-tree-window-exists-p)))
      (when tree-open
        (ps/file-tree-hide))  ;; Hide it temporarily

      ;; Check if there are exactly two windows
      (if (/= (length (window-list)) 2)
          (error "Can only toggle with exactly 2 windows!")
        ;; Order the windows geometrically (top-left first) rather than by
        ;; `window-list' order, which starts at the selected window and would
        ;; otherwise make placement depend on which pane is focused.
        (let* ((ordered (sort (window-list)
                              (lambda (a b)
                                (let ((ea (window-edges a))
                                      (eb (window-edges b)))
                                  (if (= (nth 1 ea) (nth 1 eb))
                                      (< (nth 0 ea) (nth 0 eb))   ;; same top: leftmost first
                                    (< (nth 1 ea) (nth 1 eb))))))) ;; otherwise topmost first
               (win1 (nth 0 ordered))
               (win2 (nth 1 ordered))
               (buf1 (window-buffer win1))
               (buf2 (window-buffer win2))
               (split-func (if (window-full-height-p win1)
                               #'split-window-vertically
                             #'split-window-horizontally)))
          (delete-other-windows win1)
          (let ((new-win (funcall split-func)))
            (set-window-buffer win1 buf1)
            (set-window-buffer new-win buf2))))

      ;; Reopen the file tree if it was open before
      (when tree-open
        (ps/file-tree-show))))

  (global-set-key (kbd "C-x |") 'ps/window-split-toggle)
#+end_src
